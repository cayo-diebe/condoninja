# Biblioteca sonora Ninja

Efeitos originais sintetizados, inspirados em aço, movimento e concentração. Não são gravações reais de espadas. Prévia apenas: nenhum som está integrado à interface.

MP3 mono, 44,1 kHz, 64 kb/s. Durações abaixo correspondem ao áudio antes do pequeno padding do MP3. Picos moderados e bordas suavizadas para evitar estalos. Os sons de lâmina são intencionalmente mais brilhantes que os graves iniciais.
