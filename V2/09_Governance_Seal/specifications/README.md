# Arquitetura conceitual de governança V2

Os quatro assets dizem **CONCEITO / NÃO CERTIFICA**. Usam a mesma assinatura azul. Número e nome distinguem as alternativas. Nível comercial e nível de governança são independentes.

0: Base em formação. 1: Documentado. 2: Verificável. 3: Referência.

São nomes provisórios. Nenhum selo deve ser emitido a condomínio real antes de formalizar critérios, evidências mínimas, limiares, pesos, independência do revisor, validade e contestação.

Campos de uma futura emissão: ID verificável, versão do método, escopo, período analisado, evidências consideradas, responsável, data de emissão, vencimento e estado. Estados previstos: proposto, em revisão, emitido, vencido, suspenso e revogado.

Correção de dados ou mudança relevante reabre a avaliação. Não usar dourado como recompensa paga. Não publicar os documentos privados junto do registro público.
