# Microsite V2

Abra `index.html` mantendo a estrutura do pacote. Para compartilhar um único arquivo, use `brand-concept-standalone.html`: fontes, imagens, estilos, scripts e os downloads expostos estão incorporados.

O standalone é maior porque carrega os PDFs dentro do HTML. Não é recomendado como versão para hospedar em produção; use a versão modular. Sem analytics, bibliotecas externas ou chamadas de API.

A interação demonstra identidade e evidência com dados fictícios. Não processa documentos reais. Sem JavaScript, conteúdo, tabelas expansíveis e downloads continuam acessíveis. Controles de tema, cópia e scan exigem JavaScript.
