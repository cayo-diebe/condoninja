# Arquitetura do Selo de Governança

O sistema é extensível e deliberadamente separa nível de governança de pacote comercial.

- Nível 0 — Base em formação: documentação ou evidência insuficiente. Não funciona como certificação.
- Nível 1 — Documentado: nome provisório para uma base mínima organizada.
- Nível 2 — Verificável: nome provisório para evidência rastreável e checagens consistentes.
- Nível 3 — Referência: nome provisório para o nível mais alto, sujeito a critérios e revisão humana.

Os nomes, limiares, validade, auditor responsável e processo de contestação permanecem abertos até a metodologia formal. O selo final deve exibir ano, identificador verificável e escopo avaliado. Dourado aparece apenas no nível máximo validado; não representa compra, assinatura ou status do usuário.
