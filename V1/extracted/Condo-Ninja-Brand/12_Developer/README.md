# Condo Ninja — implementação

## Começo rápido

1. Importe variables.css.
2. Use Condo Goldman somente no wordmark ou em assinaturas curtas de marca.
3. Use Geist para interface e Geist Mono para dados e evidências.
4. O botão Signal 500 usa texto Ink 950. Não use branco sobre Signal 500 para texto pequeno.
5. Em fundos escuros, prefira Paper 50 para texto e Ink 300 para texto secundário.

## Logos

- Full color: preferencial a partir de 32 px de altura.
- Simplificado: 16–24 px e favicon.
- Área de proteção: ao menos 1/4 da largura do símbolo em todos os lados.
- O lockup horizontal usa símbolo oficial e Goldman Regular 400.

## Estados de dados

Sempre combinar cor com rótulo e ícone. O azul identifica informação principal; não comunica automaticamente “positivo”. Coral comunica risco ou erro, não culpa ou fraude.

## Acessibilidade

- Foco visível: 2 px Signal 500 com offset 3 px.
- Alvo mínimo: 44 × 44 px.
- Respeitar prefers-reduced-motion.
- Texto normal deve atender WCAG AA; consulte o Brand Book para pares aprovados.
