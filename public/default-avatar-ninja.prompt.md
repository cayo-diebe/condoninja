## Prompt final

Use case: logo-brand. Create ONE square default profile avatar image for Kondo Ninja based on the provided reference image (reference for the geometric ninja shield head only). Preserve recognizable symmetric hexagonal shield silhouette and two sharp almond ninja eyes. Simplify into clean flat shapes readable at 36px. Strictly monochromatic teal: only shades of one teal hue, dark teal eye-mask, pale teal eyes, medium teal shield; no blue or other hues. Solid very pale teal background fills entire square, generous safe padding so the complete centered shield fits inside a circular crop. No text, no initials, no mockup, no grid, no border, no 3D effects, no texture, no glow. Single centered ninja head occupies about 68 percent of square width. This is a production avatar asset, not a presentation sheet.
